## 2026-11-17: src/config.py - replace retired default LLM model names
- Why: both defaults are retired. Gemini returns 404 "gemini-2.5-flash is no longer available to new users";
  Sarvam returns 400 "Model 'sarvam-m' has been deprecated ... use sarvam-105b". Every question then waits
  for four failed calls before falling back to the extractive answer. `gemini-3.1-flash-lite` is the Gemini
  model our free-tier key can call today (3.5/3.6-flash return 503, 3.7/3.8-flash return 429 quota).
- Proposed diff:
  ```diff
  -GEMINI_MODEL = os.getenv("GEMINI_MODEL", "gemini-2.5-flash")
  -SARVAM_MODEL = os.getenv("SARVAM_MODEL", "sarvam-m")
  +GEMINI_MODEL = os.getenv("GEMINI_MODEL", "gemini-3.1-flash-lite")
  +SARVAM_MODEL = os.getenv("SARVAM_MODEL", "sarvam-105b")
  ```
- Local workaround used meanwhile: `src/llm/client.py` reads `GEMINI_MODEL` / `SARVAM_MODEL` through
  `config.get_secret` (env var, then `.streamlit/secrets.toml`) before the config default, so each
  member can set the model in their git-ignored secrets file.
